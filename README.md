# Excel and Word File Processing with Python

## Project overview
This project reads a sample student registration Excel file, cleans the data using pandas, saves a cleaned Excel file, and creates a formatted Word report using python-docx.

## Files
- `process_registration.py` — automation script
- `registration_raw.xlsx` — sample input with intentional data issues
- `registration_cleaned.xlsx` — cleaned output generated by the script
- `registration_report.docx` — Word report generated by the script
- `output_screenshot.png` — screenshot-style record of the successful console output

## Requirements
```bash
pip install pandas openpyxl python-docx
```

## Run
Keep the Python script and `registration_raw.xlsx` in the same folder, then run:
```bash
python process_registration.py
```

## Cleaning operations
- Removes leading and trailing spaces
- Converts email addresses to lowercase
- Standardizes course and city names
- Converts valid dates to `YYYY-MM-DD`
- Labels missing/invalid values as `Not provided`
- Removes duplicate records by Student ID
- Sorts records by Student ID

## Expected output
The script creates `registration_cleaned.xlsx` and `registration_report.docx` in the same folder.
